# 🚢 CargoBay Proposal

A modern, interactive proposal website analyzing **CargoBay**, a digital freight forwarding and logistics platform. This project presents the company's business model, market analysis, financial insights, AI-powered logistics features, and future outlook through an engaging React application.

---

## Project Overview

The CargoBay Proposal aims to showcase:

- Executive Summary
- Company Introduction
- Business Overview
- Market Analysis
- Competitive Advantages
- Financial Analysis (Illustrative Model)
- AI-powered Logistics Solutions
- Future Outlook & Recommendations

The proposal is designed as an interactive web application instead of a traditional PDF, providing a better presentation experience.

## Features

This proposal includes AI-driven concepts to demonstrate how CargoBay can leverage artificial intelligence in logistics.

### CargoBay AI Chatbot

An intelligent assistant capable of:

- Answering logistics-related queries
- Providing shipment guidance
- Assisting users with freight services
- Demonstrating conversational AI integration

### Smart Route & Mode Recommender

A logistics recommendation engine that compares multiple transportation options based on shipment details.

The system recommends:

- Fastest Route
- Cheapest Option
- Greenest Transportation Mode

using shipment information such as:

- Origin
- Destination
- Cargo Type
- Shipment Weight

## Installation

Clone the repository:

```bash
git clone https://github.com/MorsCodee/CargoBay_proposal.git
```

Navigate into the project:

```bash
cd CargoBay_proposal
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Git Workflow

feature/aiza
